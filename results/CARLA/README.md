# CARLA Qualitative and Diagnostic Evidence

These files support controlled Clear, Rain, Fog and synthetic-Night demonstrations. They do not form a protocol-matched quantitative benchmark against ACDC or DAWN.

| Condition | Repository-facing evidence |
|---|---|
| Clear | Acceptance report, frame metrics, run summary and four review frames |
| Rain | Presentation metrics/report and `rain_review_frame_200.png` |
| Fog | Presentation metrics/report and `fog_review_frame_090.png` |
| Synthetic Night | Capture/ground-truth records, diagnostic metrics/report and two review frames |

The terms `presentation` and `diagnostic` are intentional. Stable display boxes or actor-aided association must not be described as ordinary raw-YOLO recall. Historical JSON values may retain original workstation output filenames; current repository names and the old-to-new mapping are documented in the [file-naming convention](../../docs/FILE_NAMING_CONVENTION.md).
