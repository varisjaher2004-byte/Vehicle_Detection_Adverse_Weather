# Combined-model detections on DAWN

These 120 annotated images are predictions from the Combined ACDC+DAWN checkpoint
on the DAWN portion of the mixed validation union at confidence threshold 0.4.
The complete mixed-union row-level log is in
[`../../inference_results.csv`](../../inference_results.csv).

They provide qualitative execution evidence only. Use the corrected evidence
matrix for quantitative comparison. Source images: DAWN by Mourad Kenk,
[CC BY-NC 3.0](https://doi.org/10.17632/766ygrbt8y.3); this project added the
prediction boxes and labels.
