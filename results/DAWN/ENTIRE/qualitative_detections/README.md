# DAWN Entire qualitative detections

These 120 annotated images are saved predictions from the DAWN Entire checkpoint
on the mixed-weather DAWN validation set at confidence threshold 0.4. The
row-level detections are in [`../inference_results.csv`](../inference_results.csv).

They provide qualitative execution evidence only. Use the corrected evidence
matrix for quantitative comparison. Source images: DAWN by Mourad Kenk,
[CC BY-NC 3.0](https://doi.org/10.17632/766ygrbt8y.3); this project added the
prediction boxes and labels.
